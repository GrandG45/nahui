НАХУЙ — локальная копия для себя
================================

Открой index.html двойным кликом (русская версия). Сервер, PHP и интернет не нужны.

Что работает как на оригинале:
- звук при открытии страницы и при клике по гифке (клик начинает его заново); у каждого языка свой звук,
  на страницах языков он играет по кругу с паузой 3 секунды (число LOOP_PAUSE_MS в начале audio_player.js);
- список языков внизу заголовка, редактор персональных ссылок (кнопка «друга» и /editor),
  FAQ (about.html), медиатека (media/index.html), «спасибо за нахуй»;
- красная подстановка из ссылок вида index.html#...

Добавлено от себя:
- Тёмная тема: кнопка ◐ в правом нижнем углу любой страницы, выбор запоминается.
  По умолчанию светлая, как на оригинале.
- Ссылка на свой GitHub внизу страниц языков: впиши адрес в github.js (пустая строка: ссылки нет).
- Страницы закрыты от поисковиков (noindex и robots.txt), README.md нужен для репозитория на GitHub.

Отличия от оригинала:
- Браузеры не включают звук сами, пока ты ничего не нажал. Поэтому звук стартует
  с первого клика или нажатия клавиши на странице.
- Счётчик локальный: считает открытия страницы у тебя, у каждого языка свой.
- Убраны запросы наружу: счётчик LiveInternet, пиксель home.lleo.me, кнопка GitHub.
- Нет режима ?censorship_mode=on и WAP-версий (папка wap оставлена как файлы).
- Медиатека, как и на оригинале, подтягивает маленькую иконку с beliy.ru (нужен интернет, остальное работает без него).
