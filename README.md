# Копия natribu.org для друзей

Неофициальная копия сайта [natribu.org](https://natribu.org/), сделанная для шутки между друзьями.
Оригинал и его исходники: [github.com/natribu/natribu.org](https://github.com/natribu/natribu.org).

Тексты, оформление и звуки принадлежат автору оригинала. Копия закрыта от поисковиков
(`noindex`, `robots.txt`) и не предназначена для распространения.

## Что внутри

- статичные страницы всех языков оригинала, редактор персональных ссылок, FAQ и медиатека;
- звук играет по кругу с паузой (`LOOP_PAUSE_MS` в `audio_player.js`);
- тёмная тема: кнопка ◐ в правом нижнем углу;
- счётчик локальный: каждый посетитель видит свой.

Ссылку на свой GitHub внизу страниц можно вписать в `github.js`.
